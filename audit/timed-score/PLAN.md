Introduce the explicitly versioned ranking projection mg-time-points-1, derived from those records' base, original pair count and recorded integer active seconds. Final points = base + floor(base * pairs / (10 * pairs + seconds)); base = max(1000, 10000 - ceil(4000*hints/pairs) - 2000*shuffles). Incomplete runs earn zero. Integer seconds = max(1, floor(elapsed)) both for clear UI and persisted records. Invalid/nonfinite time is rejected. Bonus is strictly below 10% for positive time, decreases smoothly without a deadline, scales by time per original pair, and preserves monotonic assistance costs.
