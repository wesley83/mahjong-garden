## Player contract

- Daily Garden: one deterministic canonical campaign geometry, seed and variety per UTC date. Resets at midnight UTC; a started board keeps its date across rollover. Archive exposes the last30 dates from launch2026-10-28 onward; no future dates. Same rules/deal for all, independent daily standings and cosmetic completion stamps. Practice/replay available; one immutable result per public alias/challenge. These are casual player-reported results, without account identity/anti-cheat promises.
- Weekly challenge rotates Golden Tiles (remove four marked tiles using ordinary matching), Clear the Layer (remove the marked top layer), Compact Garden (clear a small canonical board). Deterministic Monday-UTC identity; standings separated by challenge. Gold/layer completion can leave tiles below: core run.complete still means zero tiles; objective completion is derived separately and pauses input/time, displays the normal clear dialog and safe continuation. Target IDs follow the fixed initial layout and survive reshuffles. Standard stars/assistance/time projection applies within each challenge only.
- One journey checkpoint is suspended atomically when entering a challenge. Completion/Return to journey restores its exact tiles/time/counters, including a completed checkpoint. Switching unfinished challenges asks before replacement; choose-new-journey/restart acts explicitly on the appropriate session. Reload/import/PWA acceptance retain active context and suspended run. A mismatch is recoverable and cannot silently label another run as a challenge.
- Restore Your Garden: one seed per unique official journey completion, including already-earned progress; never repeated clears. Six chapters each offer lantern/bridge/blossom additions costing2/3/5 seeds,18 additions/60 total. Player chooses unlocked purchases/order. Inventory, earned level identities and selected home garden are local; decorations add to existing scenes without locking current themes or levels. Daily completion stamps have no spendable reward to farm. Bound retained stamp dates366.
- Friend challenge: a same-origin link encodes versioned canonical level/seed/variety or a daily/weekly ID. It shares the starting deal, not current removed tiles or personal images. Bounded strict input and invitation confirmation preserve the existing game. One-tap copy with visible selectable fallback, text result and optional locally generated1200x630 PNG card. Custom studio layouts retain their existing explicit file export/import. A completed canonical result may be explicitly saved to that friend challenge using the same durable named outbox.
- Feedback: after an actual legal player match, briefly outline remaining tiles that changed from blocked to free, without moving/replacing their face nodes. Celebrate a newly emptied nonfinal layer once with a short message/chime; final win uses its existing celebration. Undo/reload/reselection do not celebrate. New match/menu/resize/visibility/disposal cancel obsolete feedback. Respect reduced motion, mute and volume; no rapid flashing, scoring effect or input interception.
